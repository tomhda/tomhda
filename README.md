### [ryzen-ai-npu-super-resolution-notes](https://github.com/tomhda/ryzen-ai-npu-super-resolution-notes)

### [codex-app-recovery](https://github.com/tomhda/codex-app-recovery)

## Chrome Extensions

### [SILroom](https://github.com/tomhda/SILroom)
A Chrome extension that improves Chatwork's chat room UI and turns your categorized rooms into a Slack-style workspace layout.  
Completely free and open source, with no plans to charge for it.

### [silva-edit](https://github.com/tomhda/silva-edit)
A Chrome extension for quick video/audio edits right from the browser's side panel.  
Supports trimming, cropping, rotation, playback speed, loop playback (up to 3 times), volume up/down, stereo conversion, exporting split segments separately, batch thumbnail export at a set time from multiple videos, and batch stereo conversion of multiple audio files.  
Recommended if you often make edits too small to bother opening an editor for, or if you're fed up with Microsoft Clipchamp.

### [SILHack](https://github.com/tomhda/SILHack)
A Chrome extension that makes ChatGPT / Claude / Gemini / Perplexity / Messenger behave the same way: Enter for a new line, Ctrl+Enter to send.  
Also auto-selects the best available Gemini mode and adds tag-insert buttons to Chatwork.
